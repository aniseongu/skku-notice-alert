# 디자인 캡처 확인 기록

> 사용자 지시(2026-11-02): "디자인은 완성하면 캡처해서 한번씩 확인해보자. 문서화해".
> 화면을 고칠 때마다 아래 절차로 찍고, 결론을 모르는 평가자에게 점수를 받고, 이 파일에 한 판씩 남긴다. 캡처는 `docs/design/captures/<날짜>/`.

## 절차 (화면을 고칠 때마다)

1. 빌드: `cd web && npm run build`. 개발 서버: `npx vite --host 127.0.0.1` 후 `?api=sample/api/v1`.
2. 휴대폰: Playwright 412x891(Galaxy S26 울트라), 라이트와 다크, 목록과 설정 화면. 페이지가 다 그려진 뒤 찍는다(제목 글자가 보일 때까지 기다림).
3. Windows: 실제 웨일로 찍는다. `WhaleExtentions/scripts/whale-dev.sh start <주소>` 후 `whale-dev.sh shot "성대 공지" <파일>`. 평소 웨일 프로필은 건드리지 않는 개발용 프로필이다.
4. 평가: 결론을 주지 않은 새 평가자(서브에이전트)에게 스크린샷과 `docs/DESIGN.md`, calm-design ai-tells, taste critique, 웨일 DESIGN 1절을 주고 점수를 받는다. **7점 미만이면 고치고 다시 찍는다.**
5. 기록: 아래 표에 한 줄, 캡처는 1100px 폭 JPG로 줄여 저장한다.
6. 사용자에게 보여 주기 전에 위 1에서 4를 먼저 끝낸다(고치는 도중의 화면을 보여 주지 않는다).

## 남은 과제 (평가에서 나왔지만 아직 안 한 것)

- 휴대폰 큰 제목 머리(One UI, 위쪽을 비워 엄지가 닿게): 스크롤하면 작아지는 머리는 움직임이 필요해서 사용자 확인 뒤에.
- 묶음 상자 반경 14px: One UI는 20px 안팎이지만 웨일 DESIGN의 "16px 이상 금지"를 지킨다. 바꾸려면 사용자에게 묻는다.
- 상세 칸에 본문 요약: 본문 읽기(M4)가 생기면 Gemini 요약 3줄.
- 설정의 "받는 방법" 밑줄 단추를 One UI 설정 행(오른쪽 꺾쇠) 모양으로.
