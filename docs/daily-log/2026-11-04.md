## 6. [core] 설정 개요와 기기별 아캠 수신, QR 연결 (Codex)

- 후속 요청으로 아캠 수집 전체 끄기에서 기기별 수신으로 바꿨다. 휴대폰은 요약과 마감, PC는 꺼짐을 기본 제안하고 각 구독의 preferences.canvas에 저장한다. 토큰은 저장소에서 공유한다. GitHub 메타데이터 조회에서 CANVAS_TOKEN은 아직 없고 GEMINI_API_KEY만 있음을 확인했다. 실제 아이캠퍼스 토큰은 사용자가 연결 키에서 한 번 저장해야 한다.
- 설정 개요에는 알림, 관심 키워드, 캘린더, 기기 연결과 연결 키의 다섯 항목 및 화면 모드만 둔다. 입력과 고급 기능은 하위 화면 및 접힌 관리로 옮겼다. 캘린더는 구글 자동 연결 하나로 통합하고 기존 ICS 출력은 유지한다.
- 노트북의 QR을 PWA 카메라에서 읽어 연결할 수 있다. jsQR 폴백을 재사용하며 같은 origin/path와 저장소만 허용하고 사용자 확인 전에는 인증하지 않는다. 권한 대기 중 취소와 화면 이탈도 카메라를 정리한다.
- 중복된 연결 성공 및 키 저장 안내는 중립 상태 한 번으로 줄이고 키별 입력이나 수정 버튼을 누를 때만 입력칸을 펼친다. GitHub, Atlassian, Miniflux와 FreshRSS의 공식 문서 및 원본 설정 구조를 조사했다.
- Claude 위험 리뷰: 공통 Canvas 모드가 기기 설정을 막던 문제를 제거했다. 키 거절 안내는 요약과 전체 수신 기기에 모두 보내고, 선택적 구독 이전 실패가 정상 GitHub 연결을 지우지 않도록 분리했다. 최초 기본 모드의 로컬 기억과 카메라 동시 시작도 고쳤다. 수신 거부 기기만 있을 때 성공 처리는 의도된 동작이다. 알 수 없는 지문은 다른 기기 구독을 덮지 않도록 새 칸을 쓰는 기존 제약을 유지한다. 배포 잠금은 수집이 아닌 별도 deploy job으로 옮겼다.
