# 알림 기준 조정

## 1. 지금 기준과 불만 확인

- `config/rules.yaml`이 없으면 `config/rules.example.yaml`을 복사해 시작한다.
- 사용자가 말한 불만을 "놓친 글"과 "필요 없던 글"로 나눈다. 가능하면 실제 제목 예시를 받는다.

## 2. 고치기

- 규칙 형식은 `config/rules.example.yaml` 주석을 따른다. 형식 자체를 바꿔야 하면 계획을 쓰고 코드 변경(스킬 `feature-change`)으로 넘긴다.
- 키워드는 짧고 넓게(예: "인턴"은 "인턴십"도 잡는다), 제외어는 좁게 쓴다.
- 우선순위 `high`는 정말 놓치면 안 되는 것만(휴대폰이 울림). 나머지는 `default`나 `low`.

## 3. 미리 보기 (M1 이후)

```zsh
uv run skku-notice --dry-run --all      # state와 상관없이 지금 목록 전체에 규칙을 적용해 결과만 출력
```

- 결과를 사용자에게 "받을 글 N건, 안 받을 글 M건"과 제목 목록으로 보여 주고 확인받는다.
- 네트워크를 쓰기 싫으면 fixture로: `uv run skku-notice --dry-run --all --from-fixtures`.

## 4. 기록

- `config/rules.yaml`은 개인 기준이다. 커밋 여부는 사용자가 정한다(비밀은 아니지만 공개 저장소면 고민할 것). 기본은 커밋한다: `chore(rules): 장학 키워드 추가`.
