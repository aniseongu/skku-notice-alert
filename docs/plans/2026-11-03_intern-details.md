## 배경

인턴 목록은 상세를 읽지 않아 앱에서 본문을 볼 수 없다. 사용자에게 내 공지의 기준도 설명한다.

## 가져올 코드

기존 `jobs.py`, `fetch.py`, `parse.py`와 상세 보관 및 렌더링을 재사용한다. `docs/research/open-source.md`의 기존 출처를 살핀다.

## 범위 밖

로그인이 필요한 정보와 자동 지원은 다루지 않는다.

## 단계

- [x] 1. 두 사이트의 공개 상세 응답과 접근 제한을 확인한다.
- [x] 2. 제한된 요청으로 상세 수집과 저장, 표시를 구현한다.
- [x] 3. fixture 테스트, `scripts/check.sh`, 실제 접근을 검증한다.
- [ ] 4. 기록, 커밋, 정식 배포, 교차 리뷰한다.

## 위험과 되돌리기

외부 구조 변경, 서버 제한과 요청 실패 시 본문을 읽지 못할 수 있다. 기존 원문 열기를 유지한다. 커밋을 되돌려 상세 수집을 중단할 수 있다.

## 진행 메모

- 두 사이트 실제 공개 상세에서 텍스트와 이미지 본문을 확인했고 fixture와 전체 테스트가 통과했다. 실제 게시판 dry-run은 기준 파일이 없다. Claude 리뷰는 사용 한도로 실행하지 못했다.
