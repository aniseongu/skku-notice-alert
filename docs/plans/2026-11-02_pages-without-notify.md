# 알림 설정 없이 Pages 화면 배포

- 상태: 진행 중
- 마일스톤: M3
- 작성: 2026-11-02, Codex
- 시작 hash: 7c5d933
- 완료 조건: 알림 Secrets 없이 화면을 빌드하고 Pages로 배포하는 워크플로 검증, 사용자 push 확인 후 실제 주소 접속 확인.

## 배경

정식 Pages 주소는 첫 배포 전이라 404다. 기존 배포는 알림 실행 성공에 묶여 있어서 알림 키가 없으면 화면도 배포되지 않는다.

## 가져올 코드

기존 `notice.yml`의 SHA 고정 빌드와 Pages 업로드, 배포 단계를 재사용한다.

## 단계

- [x] 별도 Pages 워크플로 작성. 공개 archive가 있으면 재사용하고, 없으면 실제 공개 목록만 dry-run으로 만든다.
- [x] actionlint, 웹 빌드와 export 경로 검증.
- [x] 사용법, daily-log와 HANDOFF 갱신, 커밋.
- [ ] 사용자 push 확인 후 배포, 정식 주소 검증.

## 위험과 되돌리기

알림이나 state를 변경하지 않는다. 권한은 contents 읽기와 Pages 배포, OIDC에 한정한다. 기존 알림 배포와 동일 concurrency 그룹을 사용한다. 워크플로를 비활성화하면 중단할 수 있다.
