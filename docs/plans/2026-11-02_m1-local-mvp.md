## state 형식 (초안, 6단계에서 확정하고 D-008로 기록)

```json
{
  "version": 1,
  "sources": {
    "cse-notice": {
      "initialized_at": "2026-11-02T19:00:00+09:00",
      "seen": {
        "227923": {"first_seen": "2026-11-02T19:00:00+09:00", "status": "notified", "attempts": 1}
      }
    }
  }
}
```

`status`: `baseline`(첫 실행에 본 것), `skipped`(기준에 안 맞음), `notified`, `failed`(시도 3회 넘음). 게시판당 최근 500개만 남긴다(D-004).
