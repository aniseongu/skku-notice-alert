# 앱을 닫아도 받는 브라우저 알림과 저장된 키 표시

- 상태: 진행 중
- 마일스톤: M3, M4
- 작성: 2026-11-02, Codex
- 시작 hash: 93967d0
- 완료 조건: ntfy 없이 웨일에서 웹 푸시 수신, 알림 클릭 시 원문 열기, 저장된 키의 잠금과 새로고침 후 상태 복원 확인.

## 배경

사용자는 앱과 탭을 닫아도 웨일이 실행 중이면 Windows 알림을 받기를 원한다. 확장은 chrome.alarms와 chrome.notifications로 동작하지만 정적 웹은 서비스 워커에 푸시를 전달해야 한다. Gemini 키와 알림 주소는 실제 GitHub에 저장돼 있으나 UI가 저장 메타데이터를 복원하지 않아 재입력이 가능해 보인다.

## 가져올 코드

기존 웨일 확장의 알림 클릭과 중복 처리 흐름, pywebpush의 VAPID 발송 예제를 참고한다. PWA는 기존 Workbox generateSW에 push 리스너를 추가한다.

## 위험과 되돌리기

키와 구독 URL은 공개 파일, 로그, 브라우저 localStorage에 저장하지 않는다. GitHub Secrets에는 기존 봉인 암호화를 사용한다. 공개키만 앱에 포함한다. 현재 개인용 웹 푸시는 저장소당 브라우저 한 대를 연결한다. 부분 실패는 재시도하며 state와 알림 순서는 D-005를 유지한다. 브라우저 푸시 연결을 지우고 기존 ntfy로 되돌릴 수 있다.
