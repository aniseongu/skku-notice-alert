## 1. [core] 기기 회전과 성공 시작 이름, 아캠 알림 분리 (Codex)

- 요청: PWA는 휴대폰 회전 설정을 따르고 시작 이름은 성공. 노트북에서 아캠 설정, 아캠플러스와 겹치는 알림은 끄고 키 설정을 분리한다.
- 변경: manifest orientation 지정을 제거하고 목록의 문서 제목을 성공으로 고정했다. 아캠 알림 모드는 기본 off, 선택 시 하루 요약 또는 요약과 마감을 지원한다. 원격 CANVAS_ALERT_MODE도 off로 저장했다. 일반 설정과 별도 연결 키 화면에서 Gemini, Canvas 토큰과 프로필, 구글 연결 정보를 관리한다.
- 보안: 공개 저장소의 캐시가 비밀 저장소가 아님을 확인했다. Canvas 알림 기록은 토큰에서 파생한 키로 인증 암호화한 파일만 캐시한다. 조회된 기존 canvas-state 캐시는 0개였다.
- 검증: 전체 검사와 웹 빌드, 웹 테스트 12개 통과. 개인 환경파일 읽기를 막고 예시 규칙으로 실제 게시판 dry-run 1회, 공지 99건과 오류 없음 확인. 실제 알림 발송과 OS에 설치한 PWA의 회전 잠금은 미확인이다. 정식 배포 후 브라우저 검증 예정.
- 교차 리뷰: Claude Opus가 암호문 복호화 시 mtime 변경으로 수집이 계속 생략되는 문제와 잘못된 요약 응답의 반복을 지적했다. 원본 시각 보존과 응답 형식 실패의 시도 횟수 반영을 수정한다. 제목 고정은 사용자 요청이다.
