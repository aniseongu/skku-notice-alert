## 1. [notify] 앱을 닫아도 받는 브라우저 알림과 저장된 키 잠금  (Codex 구현, Claude 이어받아 리뷰와 커밋)

- 요청: 웨일 확장처럼 앱이나 탭을 닫아도 알림이 뜨게 해 달라. 설정에 넣은 키가 저장 안 된 것처럼 보이고 새로고침하면 사라진다.
- 변경: `webpush_notify.py`로 VAPID 웹 푸시 직접 발송(ntfy는 선택). `notify._deliver`가 설정된 모든 채널을 시도하고 하나라도 실패하면 pending(최대 3회, D-005). PWA 워커에 `push-handler.js`(학교 주소만 열기). 설정 화면에 "이 기기 알림", 저장한 키는 날짜만 기억해 잠그고 "수정하기"로 다시 연다. 저장 전 새로고침은 경고. 수동 `test-push.yml` 추가.
- 검증: `scripts/check.sh` 통과(Canvas 날짜 의존 테스트 고정 포함), `npm test` 4개, 웹 빌드 통과. GitHub Secrets에 `WEB_PUSH_PRIVATE_KEY`, `WEB_PUSH_SUBSCRIPTION` 이름 존재 확인(값은 보지 않음).
- 미확인: 정식 Pages에는 아직 푸시 코드가 없다. 기존 구독은 로컬 미리보기에서 만든 것으로 보여 배포 후 정식 주소에서 "알림 받기"를 다시 눌러야 한다. 실제 웨일 수신과 클릭, 디자인 캡처 평가는 push 뒤에 한다. Codex 한도 소진으로 Claude가 리뷰했다.
